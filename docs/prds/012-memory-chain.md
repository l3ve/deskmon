## 问题陈述

登录时，用户经常要先填账号，再填密码。有的网站把它们放在不同页面，有的工作流程还需要切换 App。原先笔记本和变量都可以取出一段文本，每填一个字段都得重新打开菜单、找到对应条目、复制，再回到输入框粘贴。需要连续填三段或更多内容时，操作次数随之增加。

用户希望把经常一起使用的几段内容按顺序保存。需要填写时，只从「回忆」选一次，之后仍用熟悉的系统粘贴快捷键完成每一步，自己决定填写位置和时机。

## 解决方案

「回忆」列出全部「记忆链」。每条记忆链有名称、可选备注，以及一条或多条按顺序保存的文本。用户在编辑页添加、删除和调整顺序，也可以把「记忆中」的一条文本作为新链的首段。

用户可在菜单栏打开「回忆」查看和管理全部记忆链，也可从桌宠右键「回忆」直接选择。选中一条链后，用户回到目标输入框，每按一次系统 `⌘V` 就粘贴下一段。链只有一段时也走同一流程。

以含 A1、A2、A3 的记忆链 A 为例：

| 用户动作 | 可观察结果 |
| --- | --- |
| 在「回忆」选中 A | 本轮从 A1 开始。用户可以回到原 App 或切换到其他 App |
| 第一次按 `⌘V` | 在当前输入框粘贴 A1 |
| 第二次按 `⌘V` | 在当前输入框粘贴 A2，允许与第一次在不同 App |
| 第三次按 `⌘V` | 在当前输入框粘贴 A3，清空本轮留在剪贴板里的内容并结束 |
| 第四次按 `⌘V` | 若期间没有新的复制操作，则无内容可贴 |
| 任意时刻主动复制新内容 | 本轮结束，下一次 `⌘V` 粘贴刚复制的内容 |

笔记本和变量的入口随新版移除。首次启动新版会清空旧笔记本和旧变量的持久数据，用户可在「回忆」新建记忆链。

## 用户故事

1. 作为经常登录多个服务的用户，我想把账号和密码保存成一条记忆链，以便只选一次就能依次填写。
2. 作为需要填写多项内容的用户，我想在一条记忆链里保存三段或更多文本，以便用同样的操作完成整组填写。
3. 作为只需复用一段文本的用户，我想建一条只含一段内容的记忆链，以便通过同一入口取用。
4. 作为创建记忆链的用户，我想填写易识别的名称和可选备注，以便下次快速找到它。
5. 作为管理多条记忆链的用户，我想打开「回忆」后看到所有已保存的链，以便浏览和选择。
6. 作为有很多记忆链的用户，我想按名称或备注搜索，以便少滚动几次就找到目标。
7. 作为常用几条记忆链的用户，我想把它们置顶，以便在列表和桌宠菜单里优先看到。
8. 作为使用鼠标的用户，我想在桌宠右键「回忆」中直接点选一条链，以便马上开始填写。
9. 作为需要管理内容的用户，我想从桌宠菜单打开「回忆」窗口，以便在一个地方编辑和搜索。
10. 作为编辑记忆链的用户，我想在同一编辑页添加、删除和调整各段顺序，以便适配表单字段的排列。
11. 作为保存命令或多行文本的用户，我想保留每段的空白和换行，以便按原样粘贴。
12. 作为粘贴敏感内容的用户，我想在普通列表和菜单只看到名称等信息，以便操作时避免旁人看到实际内容。
13. 作为核对编辑内容的用户，我想按需显示保存的文本，以便检查内容和顺序。
14. 作为填写表单的用户，我想继续用系统 `⌘V` 并自行决定何时粘贴，以便沿用现有习惯。
15. 作为使用分步登录页的用户，我想切换输入框、页面或 App 后继续粘贴下一段，以便用一轮取用完成整个流程。
16. 作为快速填表的用户，我想连续按键时仍按保存顺序粘贴，以便每个输入框拿到预期的值。
17. 作为已经贴完一轮的用户，我想下次按 `⌘V` 时剪贴板是空的，以便避免重复贴出最后一段。
18. 作为中途需要复制别的内容的用户，我想复制后立即回到正常粘贴，以便下一次按键得到刚复制的内容。
19. 作为需要从头再填的用户，我想重新选中同一条链后从第一段开始，以便重做这一轮。
20. 作为需要改用另一条链的用户，我想直接选中另一条链，以便从新链的第一段开始。
21. 作为初次启用顺序粘贴的用户，我想在缺少系统授权时看到申请位置，以便授权后重新选用。
22. 作为已经复制了一段常用文本的用户，我想从「记忆中」把它存为新链，以便少输入一次。
23. 作为使用临时剪贴板历史的用户，我想让记忆链取出的文本避开「记忆中」，以便密码或敏感文本不会出现在临时列表。
24. 作为管理本机内容的用户，我想确认后删除不再需要的链，以便清理记录并避免误删。
25. 作为从旧版升级的用户，我想在「回忆」里从空的记忆链列表重新开始，以便清理原来分开保存的笔记和变量。

## 实现决策

### 回忆窗口与原生菜单

- 菜单栏「回忆」打开管理窗口。桌宠右键「回忆」按置顶顺序列出记忆链，另提供「打开回忆…」和「记忆中」取用入口。
- 列表和菜单只读取记忆链元数据。窗口可按名称和备注搜索，选中记忆链即开始本轮取用并关闭窗口。窗口收起时尝试交还原 App 的焦点。后续每次粘贴以按键时的前台 App 为目标。
- 编辑页负责添加、上移、下移、移除及保存，视觉顺序即粘贴顺序。值默认遮盖，编辑时可以主动显示。删除应经系统确认。
- 保留「记忆中」的临时捕获和单条复制、忘记能力。启动时的剪贴板内容只作为基线。新复制的纯文本去重后最多保留 10 条，退出时清空。

### 记忆链存储

- 持久记录包含唯一标识、名称、可选备注、置顶状态和有序文本。名称必填且在列表中唯一，每条链至少包含一段非空文本。保留重复值、首尾空白和换行。
- 开发版沿用最多 50 条持久记录的上限。搜索与列表使用名称、备注、段数等元数据。取用内容不会出现在搜索、菜单、统一提醒或「记忆中」。
- 数据加密保存在本机。识别到旧版本加密数据时，原子替换为空的新版数据。重新启动应保留已有新版记录。旧版文件清理、升级重试和新版保存可在独立测试目录验证。

### 顺序粘贴

- 顺序粘贴模块接收有序文本并维护本轮进度。一次只启用一条链。每次取用从第一段开始，进度只保存在运行期。
- 仅在本轮内注册系统 `⌘V`。每次触发写入当前段，再把粘贴事件转给前台 App。连续按键按次序处理，给目标 App 留出读取本段剪贴板的时间。
- 使用 macOS 剪贴板的变更序号识别用户复制，复制相同文本也会结束本轮。清理前校验剪贴板仍是本轮写入，保留期间由用户或其他 App 写入的新内容。
- 贴完、用户主动复制、改选记忆链或退出时结束旧的一轮。开发版使用 **5 分钟空闲超时**。结束后归还系统粘贴快捷键。重新选择同一条链可从第一段开始。
- 使用 macOS 辅助功能授权转发粘贴。授权缺失或快捷键注册失败时给出可操作的错误提示，保持系统普通粘贴可用。安全输入场景使用已在本机验证的原生全局快捷键方式。

## 测试决策

- 测试以用户可观察的结果为准，包括选择后的窗口行为、输入框中收到的文本、剪贴板归属、历史列表和重启后数据。加密格式及原生事件内部调用可以在满足这些结果的前提下演进。
- **加密存储**沿用临时目录和虚拟数据测试。覆盖有序文本往返、重复值和空白、旧版本清理、新版重启后保留，以及升级重复执行。
- **窗口和菜单**覆盖新建三段、调整顺序、保存、重新打开、搜索、直接选用、原生删除确认及私密值遮盖。用实际的「回忆」窗口核对后端收到的保存顺序。
- **macOS 粘贴**用测试文本在普通输入框、安全密码框和不同 App 中完成一轮。覆盖单段、多段、快速连按、第四次为空、主动复制相同或不同内容、重新选链和空闲超时。
- **权限和回归**覆盖辅助功能未授权时的提示与普通粘贴、剪贴板历史的基线与去重，以及私密值不进入临时历史。安装包验收沿用项目的 macOS 实机清单。[V1 手工验收清单](../qa/v1-smoke-checklist.md)

## 范围之外

- 网站识别、固定账号密码字段、自动切换字段和提交表单。
- 顺序循环、专用取密码快捷键，以及用 App 菜单或输入框右键代替系统 `⌘V` 推进顺序。
- 旧笔记或变量的配对、导入和恢复。
- 云同步、跨设备同步及独立密码库能力。

## 补充说明

- 5 分钟空闲超时、50 条容量和剪贴板短暂交接时间属于开发版参数。用户确认的交互是选一次、按系统 `⌘V` 依序取值、跨 App 继续、用完清空，以及主动复制立即退出。
- 开发版已用隔离配置验证新建、排序、保存和选用。原生测试覆盖跨 App、安全密码框、快速按键、第四次为空以及主动复制保留新内容。用户于 2026-11-17 确认本机安装版测试通过。
