## 边界

本方案只重做视觉，不改变功能、信息架构、窗口布局、入口分配或操作流程。

- 桌宠外貌和 App Icon 原样保留。
- 设置仍使用摘要侧栏和纵向面板。
- “记忆力”仍使用顶部筛选/搜索、左侧列表、右侧详情。
- 统一提醒的队列、逐字显示、点击、悬停和拖拽规则不变。
- 截图的框选、标注、撤销、丢弃、保存和失败修复规则不变。
- 菜单栏菜单与宠物右键菜单继续使用 macOS 原生菜单。

## 视觉目标

Deskmon 应像一件安静地陪在桌面上的 macOS 小工具，而不是网页后台或完整游戏界面。普通工作窗口保持清晰、柔和和宽松；宠物提醒、像素图标与状态反馈负责表达角色感。

## 视觉语言

### 明暗与材质

- 只设计浅色系，不提供深色变体。
- 窗口框架、标题区和侧栏使用低透明度的淡紫雾面材质。
- 表单、列表、详情和私密内容使用暖白不透明实面。
- 普通面板依靠底色差和 `1px` 细边框分层，不使用悬浮卡片阴影。
- 阴影只用于真正浮在内容或桌面之上的提醒、截图工具栏和临时反馈。

### 色彩

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| Window Snow | `#FBF9FC` | 主内容底色 |
| Mist Lavender | `#F1EDF4` | 标题区、侧栏、次级底色 |
| Soft Lavender | `#E8DDF0` | 选中底色、轻强调 |
| Deskmon Lavender | `#A987C0` | 品牌色、主要操作、焦点 |
| Lavender Ink | `#624A74` | 品牌色上的深色文字与图标 |
| Primary Ink | `#302C38` | 主文字 |
| Secondary Ink | `#746E7B` | 辅助文字 |
| Hairline | `#DDD6E2` | 细边框与分隔线 |
| Success | `#5F9174` | 成功状态 |
| Warning | `#B9854C` | 警告状态 |
| Danger | `#B86066` | 危险与错误状态 |

大面积只使用暖白、雾灰和淡紫。成功、警告、错误仅在表达真实状态时出现，不为不同功能分配独立主题色。

### 字体

- 中文与普通界面使用 macOS 系统字体：`-apple-system`、`BlinkMacSystemFont`、`PingFang SC`。
- 命令、路径、变量 key 等技术内容使用系统等宽字体。
- 不使用像素字体；像素感由图标、边框和短促动效表达。
- 标题建议 `20–24px / 600`，分组标题 `15–17px / 600`，正文 `14–15px / 400`，辅助文字 `12–13px / 400`。

### 间距与形状

- 使用宽松桌面密度：窗口边距 `24–32px`，分组间距 `20–24px`，控件高度 `32–36px`，列表行最小高度 `52px`。
- 窗口内容面板圆角 `14–16px`；输入框和按钮圆角 `9–11px`；徽章圆角 `7–9px`。
- 普通结构保持柔和圆润；像素切角只出现在品牌标记、像素图标、提醒尖角和状态点。

### 图标

- 功能图标使用统一 `16px` 或 `20px` 像素网格，不混用普通线性图标。
- 默认图标为深灰或雾灰；选中与主要操作变为淡紫；语义状态按成功、警告、危险着色。
- 图标不可单独承担高风险操作含义。删除、保存、权限修复等关键动作保留文字或 tooltip。
- 原生菜单只给倒计时、区域截图、记忆力和设置等主要入口增加单色像素图标，其余项目保持文字。

## 组件规则

### 按钮

- 主要按钮：淡紫实底、深紫文字，不使用高饱和纯色。
- 次要按钮：暖白实底、细边框。
- 危险按钮：浅红底或红色文字，面积保持克制。
- 图标按钮：正方形暖白底；选中时使用 Soft Lavender 底色和 Deskmon Lavender 图标。

### 输入与选择

- 输入框始终使用不透明暖白底，避免磨砂背景降低文字对比度。
- 分段控件使用 Mist Lavender 轨道，选中项使用 Soft Lavender 实面。
- 焦点环使用半透明淡紫外环，不使用浏览器默认蓝色。
- Switch 使用淡紫轨道和暖白圆点，关闭时使用雾灰轨道。

### 状态与反馈

- 保存、复制和短时完成反馈使用小型内联状态，不新增大面积 toast。
- 错误继续出现在当前任务附近；红色只用于错误信息、危险操作和必要边框。
- 私密 value 使用独立暖白实面和像素锁图标；默认仍显示掩码，不在列表或搜索中泄露。

## 窗口规则

### 设置

- 保留顶部“偏好设置”、左侧 Deskmon 摘要和右侧纵向面板。
- 侧栏采用轻磨砂淡紫底，摘要项用底色差区分，不做可点击导航外观。
- 右侧面板保持纵向滚动，活动区域预览仍是最后一个主要面板。

### 记忆力

- 保留标题、来源筛选、搜索、新增变量、左侧列表和右侧详情。
- 筛选与搜索位于同一条轻磨砂工具区；列表和详情使用暖白实面。
- 选中行使用淡紫底色和左侧像素状态条，不用粗描边或阴影。
- value 默认隐藏；展示、复制、编辑和删除入口保持原位置和原语义。

### 统一提醒

- 从现有深色 RPG 外观统一改成浅色像素对话框。
- 主卡使用暖白实面、深灰像素描边、淡紫叠卡和清晰桌面投影。
- 错误消息只增加克制的红色像素强调线，不改变宠物素材。
- 多行高度、叠卡层数、逐字时序和点击行为全部沿用现有规则。

### 截图与标注

- 选区外遮罩继续保持中性深色，不染成大面积紫色。
- 选区使用淡紫像素边框与暖白尺寸标签。
- 标注工具栏改为暖白悬浮条，全部工具使用单色像素图标；当前工具使用 Soft Lavender 选中底。
- 保存按钮使用淡紫实底；丢弃保留危险语义；保存失败反馈仍跟随工具栏出现。

## 动效

- 普通悬停、面板反馈和状态变化使用 `120–180ms` 柔和连续过渡。
- 宠物提醒展开、选中状态点和像素图标反馈可使用 `2–4` 帧短促步进。
- 不让列表滚动、文本输入或普通按钮使用逐格动画。
- 尊重 `prefers-reduced-motion`：移除位移和逐格装饰，保留必要的透明度与状态变化。

## 验收检查

- 普通窗口是否仍像 macOS 桌面工具，而不是网页后台？
- 所有核心文本是否落在不透明实面上？
- 除真正悬浮元素外，是否避免了卡片阴影？
- 像素图标在 `16px` 与 `20px` 下是否仍可辨认？
- 宠物提醒在浅色网页、深色壁纸和复杂桌面上是否都有清楚轮廓？
- 变量 value 是否在列表、搜索、菜单和普通反馈中持续隐藏？
- 原生菜单是否保持系统行为，只做少量品牌图标增强？
- 宠物素材与 App Icon 是否未被重新绘制或修改？
